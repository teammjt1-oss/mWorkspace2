# 테마

테마는 몇 개의 **축**으로 이루어지고, 축 값은 모든 앱에 한 번에 적용됩니다. 아래에서 바꾼 값은 쿠키에 저장되어 web, app, docs에 똑같이 적용됩니다. 로컬에서는 포트가 달라도 쿠키를 함께 씁니다.

어느 앱에서든 화면 오른쪽 아래의 **테마** 버튼을 누르면 같은 조절 패널이 열립니다. 패널은 화면을 가리지 않는 창이라 열어 둔 채로 페이지를 쓸 수 있고, `Esc`나 **닫기**로 닫습니다. 패널은 각 앱 루트 레이아웃의 `<ThemePanel />`이 그립니다. 앱에서 빼려면 이 줄을 지웁니다.

## 축

| 축     | 바뀌는 토큰                                         | 선택지                               |
| ------ | --------------------------------------------------- | ------------------------------------ |
| 모드   | `<html>`의 `.dark` 클래스                           | 라이트, 다크, 시스템                 |
| 강조색 | `--primary`, `--primary-foreground`, `--ring`       | 무채색, 파랑, 보라, 초록, 주황, 장미 |
| 라운드 | `--radius` (`rounded-sm`~`rounded-xl`이 따라감)     | 없음, 작게, 보통, 크게               |
| 그림자 | `--m-shadow-*` (`shadow-2xs`~`shadow-2xl`이 따라감) | 평면, 낮게, 높게                     |
| 글꼴   | `--font-sans`                                       | 고딕, 명조, 고정폭                   |

## 동작 방식

1. 축과 선택지는 `packages/ui/src/theme/axes.ts` 한 곳에서 정의합니다.
2. 루트 레이아웃의 `<ThemeHead />`가 모든 선택지의 CSS와 초기화 스크립트를 `<head>`에 넣습니다. 이 CSS는 사용자와 무관하게 항상 같아서 페이지가 정적 렌더링을 그대로 유지합니다.
3. 초기화 스크립트는 첫 페인트 전에 쿠키 `m_theme`를 읽어 `<html data-primary="blue" …>` 같은 속성을 붙입니다. 그래서 화면이 번쩍이지 않습니다.
4. 값을 바꿀 때는 `setTheme()`을 호출합니다. 쿠키에 저장하고 같은 적용 함수를 다시 실행합니다.

## 컴포넌트를 쓸 때 지킬 것

- 색은 역할 토큰으로만 씁니다. `bg-background`, `bg-card`, `bg-muted`, `text-muted-foreground`, `bg-primary`처럼 쓰고 `bg-white`, `text-gray-500`, `dark:` 짝은 쓰지 않습니다.
- 그림자는 `shadow-*` 클래스를 그대로 쓰면 그림자 축을 따라갑니다. 임의 값(`shadow-[…]`)은 축을 무시하므로 쓰지 않습니다.
- 둥글기는 `rounded-sm`~`rounded-xl`을 씁니다. `rounded-[6px]` 같은 고정값은 라운드 축을 무시합니다.

## 축 추가하기

`axes.ts`의 `AXES`에 축과 선택지를 추가하고 `DEFAULT_THEME`에 기본값을 넣은 뒤, `stylesheet.ts`에서 그 축의 CSS 변수를 출력합니다. 쿠키 검증과 조절 패널은 `AXES`를 읽어 자동으로 따라옵니다.
